A program that writes the most shameless lie for make.fun to
`/output/entry.txt`, for the make.fun competition
[The Most Shameless Lie](https://make.fun/bounty/u-danu-the-most-shameless-lie-fbb85bc6).

## Run it

```sh
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 22 characters and 5 words, inside the 1 to 88
character gate and the 1 to 5 word limit, and exactly one line.

## The entry

```
I read it. Ignored it.
```
